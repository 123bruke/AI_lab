# AFRO Lab • 4D Ultra Cinema Virtual Laboratory & Landing Experience

A cutting-edge landing page and interactive scientific environment built with **Next.js 16**, **React 19**, **Three.js (WebGL)**, and **Tailwind CSS**.

This repository contains the official homepage for **AFRO Lab**, featuring an immersive 4D Ultra Cinema atomic simulation, 4D volumetric bubble background with frosted glass blur separation, and a clean minimalist researcher interface.

---

## 🌟 Key Features

- **4D Ultra Cinema Atomic Universe**:
  - Full-viewport WebGL background on the hero section featuring large, photorealistic moving **protons**, **neutrons**, and **electrons**.
  - PBR metallic shaders, studio 4-point cinema lighting, continuous 4D hyperspace orbital precession, and quantum probability clouds.
  - Interactive mouse parallax tilting the camera around the atom with fluid inertia.
- **4D Volumetric Bubble Background & Frosted Glass Separation**:
  - 4D hypersphere fluid bubble simulation continuously morphing through $w$-axis hyperspace projections.
  - Edge-to-edge frosted glass blur separation layer (`backdrop-blur-[60px] md:backdrop-blur-[80px]`) diffusing background bubbles into soft, glowing atmospheric bokeh.
- **Minimalist Header & Navigation**:
  - Clean logo icon with crisp "AFRO Lab" typography.
  - Pristine, modern **white** Sign In button with a minimalist Google-style authentication modal.
- **Clean Google-Style Component Icons**:
  - Streamlined, human-crafted Google Material style SVGs with generous whitespace and zero clutter.
- **AI Research Assistant**:
  - Interactive floating chat assistant tuned for chemical reactions, spectroscopy, calorimetry, and virtual physics guidance.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **UI Library**: React 19
- **3D Graphics**: Three.js (WebGL PBR)
- **Styling**: Tailwind CSS
- **Motion**: Framer Motion
- **Icons**: Lucide React & Google Material Style SVGs

## 🚀 Getting Started

### Installation
```bash
cd lab1-front-main
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to experience the 4D Ultra Cinema Atomic Universe.

### Production Build
```bash
npm run build
npm run start
```
